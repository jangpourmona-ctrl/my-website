# IT Infrastructure Concept for a Small Business

**Portfolio Case Study | IT Systems & Business Requirements**

## Scenario
A fictional company has approximately 20 employees and wants to modernize its IT environment.

The company needs:
- reliable user accounts
- secure file storage
- shared communication
- regular backups
- basic security controls
- scalable infrastructure

## Requirements

### Users
Each employee should have an individual account with appropriate access rights.

### Files
Business documents should be stored centrally with controlled access.

### Communication
The company needs professional email, calendar and collaboration tools.

### Backup
Important business data should be backed up regularly and recovery should be tested.

### Security
The baseline should include:
- multi-factor authentication
- strong passwords
- least-privilege access
- software updates
- phishing awareness
- backup and recovery procedures

## High-Level Architecture

## Implementation Plan
**1 — Requirements:** Interview users and document business needs.

**2 — Design:** Compare solutions based on cost, security, usability and scalability.

**3 — Pilot:** Test with a small group.

**4 — Rollout:** Migrate users and data in controlled stages.

**5 — Training:** Provide user training and security awareness.

**6 — Review:** Measure reliability, adoption and support requests.

## Decision Criteria
| Criterion | Question |
|---|---|
| Security | Does the solution protect company data? |
| Cost | Is it affordable for a small business? |
| Scalability | Can it grow with the company? |
| Usability | Can employees use it easily? |
| Support | Can problems be resolved quickly? |
